# 🌱 শীম তথ্য অ্যাপ (Sheem Info App)

এটি একটি Flutter ভিত্তিক মোবাইল অ্যাপ্লিকেশন যেখানে শীম (Bean) সম্পর্কিত তথ্য সংরক্ষিত রয়েছে।  
অ্যাপটি দুই ধরণের ব্যবহারকারীর জন্য ডিজাইন করা হয়েছে:  
1. 👨‍🌾 চাষিদের জন্য তথ্য  
2. 👨‍👩‍👧 সাধারণ মানুষের জন্য তথ্য  

---

## ✨ Features
- 📖 শীমের প্রকারভেদ, উপকারিতা, বাজারদর, প্রাপ্তি স্থান ইত্যাদি তথ্য
- 🖼️ সুন্দর UI ডিজাইন সহ লোকাল অ্যাসেট থেকে ইমেজ লোড
- 📱 Farmer এবং Non-Farmer আলাদা আলাদা সেকশন
- 🌐 ভবিষ্যতে Web এবং Mobile দুই প্ল্যাটফর্মেই রান করবে
- 🎨 Attractive gradient background এবং material card design
